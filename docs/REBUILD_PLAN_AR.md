# خطة إعادة البناء المطابق — Small-Cap Radar

هذه الخطة هي بوابة العمل الجديدة. لا تُعتبر أي مرحلة مكتملة إلا بعد وجود دليل قابل للتكرار.

## المرحلة 0 — تثبيت المرجع

- اعتبار `smallcap-radar.higgsfield.app` واللقطات `IMG_4215–IMG_4224` مصدر الحقيقة البصري.
- اعتبار README والـPDF مصدر الحقيقة للمحرك، مع تسجيل أي نقطة غير قابلة للاستخراج بدل تخمينها.
- حفظ قاموس المصطلحات العربي حرفيًا: القيم، الأزرار، المعايير، حالات السهم، رسائل الخطأ، وتسميات الرسم.

## المرحلة 1 — عقد البيانات

- تعريف Snapshot موحّد لكل سهم مع `asOf`, `availableAt`, المصدر، الفترة، العملة، والثقة.
- فصل لقطة المسح عن التحقق العميق.
- منع أي قيمة افتراضية للصفر عند فقدان البيانات.
- منع البيانات المستقبلية والتعارض بين المصادر من دخول القوائم.

## المرحلة 2 — المحرك

- محرك واحد يقرأ مواصفة Core أو Bounce دون تكرار Thresholds.
- Legacy يبقى Benchmark فقط للمقارنة.
- Gates قبل Score، و`UNKNOWN` لا يساوي PASS.
- Core: بوابات الحجم والسيولة والإيراد/EV-S والربحية/الانعطاف وديناميكية الأسهم.
- Bounce: هبوط 12 شهرًا، القرب من قاع 52 أسبوعًا، MA30W، التخفيف والسيولة والحجم، مع هدف +20% ووقف −15% وخروج زمني 3 أشهر.
- كل سهم مقبول يجب أن يملك سببًا ودرجة وتفصيل عوامل قابلًا لإعادة الحساب.

## المرحلة 3 — خط البيانات والأداء

- universe كامل، تنظيف الأوراق غير القابلة للاستثمار، ثم دفعات quotes وSEC Frames.
- إثراء التاريخ للمرشحين فقط، مع checkpoint وlease وretry ومؤشرات تقدم صحيحة.
- عدم استبدال آخر نتيجة مكتملة بنتيجة فحص جارٍ.
- اختبار 15,000 رمز، rate-limit، فشل مزود، وانقطاع worker.

## المرحلة 4 — الواجهة المطابقة

- هاتف RTL أولًا، ثم سطح المكتب.
- القائمتان الأساسيتان فقط: `القيمة` و`الارتداد`، وقائمة `المفضلة` منفصلة.
- لا تظهر `مؤهلة` أو `مستبعدة` كوجهات أو فلاتر رئيسية.
- بطاقات الأسهم، الترتيب، الألوان، الشارات، الرسم، الدرج السفلي، وملف الشركة تُقارن بصور مرجعية عبر لقطات آلية.

## المرحلة 5 — ملف الشركة

- رأس السهم والنسخ والمفضلة والدرجة.
- ملخص النشاط بالعربية، المؤشرات المالية، الرسم والفترات، كل معيار وسبب حالته.
- متوسط أهداف المحللين، نطاق 52 أسبوعًا، مفاجآت الأرباح، backlog، Form 4، الأخبار، والمصادر؛ الحقل غير المتاح يظل واضحًا كغير متاح.

## المرحلة 6 — بوابة القبول

- اختبارات محرك كاملة.
- اختبارات API وحالة الفحص والاستئناف والإشعارات.
- مقارنة مرئية لكل شاشة.
- فحص يدوي للهاتف وسلوك فتح السهم والمفضلة وتبديل القائمتين.
- لا نشر نهائي قبل تسجيل نتيجة كل بند.
