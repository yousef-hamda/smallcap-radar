## الأسباب المثبتة في الكود

- terminal partial كانت محصورة عند 99.99 رغم استنفاد الطابور؛ هذا خلط بين اكتمال العمل واكتمال البيانات.
- النص المؤقت «بدأ الفحص» لم يُستبدل عند انتهاء polling.
- full scan يحسب نسبة الأسهم، لكنه لم يكن يثبت مراجعة corporate actions، فبقيت بوابة Bounce ناقصة لجميع المرشحين.
- Core يُنشأ بـdeathSpiral=unknown وثقة C، ولا يوجد مسار جماعي يستكمل مراجعة مخاطر التمويل أو تحقق مستقل من مصدرين. هذا الإصدار لا يحل تلك الفجوة.
- التاريخ كان يعتمد على Nasdaq لكل مرشح، بست شركات لكل دفعة، ومحاولات داخل الطلب ثم إعادة المحاولة على مستوى الجولة.
- API الرئيسي يخفي غير المؤهل وفق المواصفة، ولم توجد شاشة تعرض الأسباب لكل شركات الجولة.

## الإصلاح المنشور في هذه الحزمة

- النسبة تصبح 100.00 عند انتهاء العمل الجزئي أيضًا، مع نص نقص البيانات؛ لا تتغير حالة partial إلى complete.
- تحديث رسالة إنهاء الجولة؛ تصحيح النص الفارغ بعد وجود لقطة محفوظة.
- إضافة تقرير محفوظ لكل شركة خارج القوائم الرئيسية: إجماليات PASS/FAIL/UNKNOWN، أسباب البوابات، وصفحات 25 شركة، وإمكانية فتح الملف الحالي.
- GET /api/scan-report?runId=…&strategy=core|bounce&offset=0: 200، 400 للمدخلات غير الصالحة، 404 للجولة الغائبة، 503 لخطأ قاعدة البيانات. لا ينقل universe أو secrets.
- Yahoo daily chart يسبق Nasdaq؛ محاولة واحدة لكل مصدر بمهلة 3 ثوان، وإعادة المحاولات الدائمة تبقى في scanner. مسار fallback موسوم صراحة.
- 18 مرشحًا لكل خطوة، بستة طلبات متزامنة كحد أقصى، وتاريخ 550 يومًا مع cache يومي.
- مراجعة التجزئات تتطلب أحداثًا صالحة وتغطية كامل فترة الأسهم ودليلًا زمنيًا؛ null أو نقص التغطية لا يساوي عدم وجود splits. لا يعاد تطبيق عامل التجزئة على لقطة مراجعة.
- لا تُستخدم adjclose المعدلة بالتوزيعات لمقارنتها بالسعر الحالي؛ parser يستبعد المستقبل والجلسة اليومية غير المكتملة والمكرر والقيم غير الصالحة.
- لم تتغير حدود القبول أو الأوزان. أزيلت قبل الإصدار حدود تمويل تخمينية وتخفيف متطلبات المصدرين كانت في مسودة غير منشورة؛ المرجع لا يثبتها.

## ما لم يُثبت

- لم يُنفذ فحص سوق إنتاجي كامل بعد هذه الحزمة. لا عدد نتائج مضمون ولا زمن مضمون ولا ادعاء تطابق كامل.
- اختبار حي مباشر لـYahoo من بيئة التنفيذ تعذّر بسبب إلغاء موافقة الشبكة قبل اتخاذ القرار. اختبارات parser والتكامل لا تثبت إتاحة المزود من Cloudflare.
- Core يحتاج مواصفة/تحقق مخاطر التمويل وبيانات حديثة وتحققًا مستقلاً من المصادر؛ لا يجوز تجاوزه لإظهار نتائج.
- Safari/iPhone وChrome Android الفعليان، وصول push للهاتف، وأهداف المحللين والأخبار الشاملة غير مقبولة نهائيًا بعد.
- استرجاع بيانات الأسعار الحالية عبر Yahoo ليس dataset تاريخيًا point-in-time صالحًا وحده لاختبار رجعي.
