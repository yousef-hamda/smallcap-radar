# مواصفة dataset البحثية

هذه المواصفة تمنع تدريب الدرجة على لقطة حالية مع إعادة تسميتها كتاريخ.

## صف الإشارة

كل صف هو إشارة قابلة للتداول عند 'asOf':

| الحقل | الشرط |
|---|---|
| 'symbol', 'asOf' | معرف ثابت وتاريخ جلسة معروف |
| 'features' | كل عامل محوّل إلى 0..1 من عقدة 'strategy-spec'، مع الاحتفاظ بالقيمة الخام |
| 'availableAt', 'periodEnd', 'sources' | خرائط لكل عامل حاضر؛ لا يقبل المختبر قيمة بلا مصدر وفترة وتوقيت متاح لا يتجاوز 'asOf' |
| 'safety' | حالات 'PASS/FAIL/UNKNOWN'؛ 'UNKNOWN' لا يصبح PASS |
| 'outcome' | نتيجة مستقبلية مع 'observedAt' بعد 'asOf'، و'grossReturn' و'costBps' و'netUtility' |
| 'securityMaster' | 'listedAtAsOf=true' وحالة النتيجة: 'listed/delisted/acquired/bankrupt' |
| 'benchmark.score' | درجة النموذج المرجعي المجمد من 0 إلى 1 للمقارنة خارج العينة |

يجب حفظ الصفوف المستبعدة وسبب الاستبعاد. لا تُحذف الشركات التي فشل مزودها بصمت.

## مصادر مطلوبة

- security master تاريخي من Nasdaq/NYSE أو مصدر موثق يتضمن الإدراج والإيقاف.
- أسعار OHLCV يومية معدلة corporate-action adjusted، مع أول افتتاح بعد الإشارة.
- corporate actions، split، offering، وتغير عدد الأسهم.
- SEC Company Facts/Frames وfiling timestamps لبناء facts نقطة-بزمن.
- Form 4، مع احتساب transaction code 'P' فقط للمشتريات الداخلية.
- universe للشركات المشطوبة أو منهج واضح لتصحيح survivorship bias.
- تكاليف تداول وانزلاق وحالة السيولة وقت الإشارة.

المصدر المجاني قد يثبت الأسعار أو filings جزئيًا، لكنه لا يثبت تلقائيًا dataset survivorship-free كاملًا. كل fallback يجب أن يحمل 'fallback: true' وتاريخ توفره.

## بناء outcome

### Bounce

يبدأ التنفيذ من أول افتتاح متاح بعد الإشارة. الهدف +20%، الوقف −15%، انتهاء بعد ثلاثة أشهر. عند لمس الهدف والوقف في الشمعة نفسها يُسجّل الوقف أولًا. إذا حدثت فجوة، يستخدم التنفيذ سعر الافتتاح، وإذا انتهت المدة دون شمعة لاحقة يبقى الصف censored ولا يُسمّى نجاحًا.

### Core

يحتاج كل صف إلى نافذة 12 و24 شهرًا، العائد، أقصى هبوط، تكلفة التنفيذ، ومؤشر فشل/شطب. لا يسمح بربط fundamentals الحالية بنتيجة تاريخية.

## فحوص قبل المختبر

1. منع 'availableAt > asOf' و'periodEnd > asOf'.
2. منع duplicate 'symbol + asOf'.
3. منع nonfinite والنتيجة التي تبدأ قبل الإشارة.
4. التحقق من أن كل صف يحمل source وhash للدفعة.
5. قياس التغطية حسب الشهر والقطاع والحجم، لا العدد الإجمالي فقط.
6. فصل الشركات المشطوبة عن الناجية وتسجيل السبب.
7. تجميد dataset قبل فتح test holdout.
8. اشتراط تغطية شهرية لا تقل عن 80%، وتغطية 99% للـsecurity master، ووجود حالات شطب/إفلاس فعلية.
9. لا يعتمد المرشح ما لم يتفوق على benchmark المجمد في AUC والمنفعة الصافية، ويكون الحد الأدنى لفاصل bootstrap المجمع حسب الشركة موجبًا.
10. إذا تعلم النموذج إشارة سالبة لعامل معرف على أن الأعلى أفضل، يحجب النشر؛ لا تحول القيمة المطلقة للمعامل إلى وزن موجب.
